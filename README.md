
# Online Gamified System - MERN Stack

This project is an **Online Gamified System** built with the **MERN stack** (MongoDB, Express.js, React.js, Node.js) and **Tailwind CSS** for styling. The system is designed to engage users with gamification features and provides a fun, interactive learning experience.

## Features:
- **Backend**: Node.js with Express for handling API requests and MongoDB as the database.
- **Frontend**: React.js for the user interface and Tailwind CSS for responsive design and styling.
- **Gamification**: Points, badges, and leaderboards to track user progress.

## Installation

To get started with this project, follow the steps below:

### 1. Clone the Repository

Clone the repository to your local machine:

```bash
git clone https://github.com/IT21060144/GAME.git
```

### 2. Install Backend Dependencies

Navigate to the backend folder and install the required dependencies:

```bash
cd GAME/backend
npm install
```

### 3. Install Frontend Dependencies

Navigate to the frontend folder and install the required dependencies:

```bash
cd ../client
npm install
```

### 4. Start the Backend

To start the backend server, navigate to the backend folder and run the following command:

```bash
cd GAME/backend
npm start
```

This will start the server on the default port (usually `http://localhost:5000`).

### 5. Start the Frontend

To start the frontend development server, navigate to the frontend folder and run the following command:

```bash
cd GAME/client
npm start
```

This will start the React development server and open the application in your default browser (usually `http://localhost:3000`).

## Usage

1. **Backend**: The backend provides a REST API to manage the gamification system, including user management, leaderboards, and game data storage.
2. **Frontend**: The frontend provides a user-friendly interface to interact with the system, track progress, earn points and badges, and view the leaderboard.

## Technologies Used
